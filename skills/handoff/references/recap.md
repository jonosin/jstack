# Recap

Use recap to resume the same work in an attended session. Its job is orientation, not a session
transcript or a new plan.

Write an ordered list of the real files the next agent should read:

```markdown
# Continue <topic>

## First action
Read <full-handoff-path> and restate your understanding before proceeding.

## Read in order
1. `<path>` — <why this comes first>

## Suggested skills

```

The annotations give the reading purpose and sequence. Replace `<full-handoff-path>` with the
absolute path of the saved handoff file. List only skills that will help the next agent.
