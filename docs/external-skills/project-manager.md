## Workflow summary

Agree on the outcome, constraints, completion criteria, implementation owner, environment, and project record. Split delivery into small milestones with observable acceptance checks.

Continue the selected implementation thread. Identify each exact build and distinguish implementation reports from independent runtime evidence. Test the core journey, relevant regressions, interruptions, and repeated actions.

Send reproducible failures back for fixes. Obtain a new identified build, repeat the failed checks, and preserve both failed and passing evidence. Keep milestones unverified while required checks remain blocked or untested.

Maintain a private project record with decisions, current status, build identities, issues, and dated evidence. Continue within authorization until the agreed outcome, a user pause, or a concrete blocker.
